# 🔌 جسر MT5 المجاني — دليل التشغيل خطوة بخطوة

هذا الجسر يربط **موقعك** بحسابك الحقيقي في **MetaTrader 5** (XM / IC / FBS / Exness…)
بشكل **مجاني ودائم**، بدون أي اشتراك.

> ⚠️ **ابدأ بحساب تجريبي (Demo) دائماً.** لا تستخدم حساباً حقيقياً حتى تطمئنّ 100%.

---

## 🧩 الفكرة باختصار

```
موقعك (Vercel)  ──HTTPS──►  رابط Cloudflare الثابت  ──►  جهازك  ──►  MT5  ──►  وسيطك
```

الموقع يُرسل أوامر (شراء/بيع/تعديل وقف) إلى **جسر يعمل على جهازك**، والجسر ينفّذها
في MT5 بالحزمة الرسمية المجانية `MetaTrader5`.

## 🚀 خطوات التشغيل

### 1) ثبّت مكتبات الجسر
افتح موجّه الأوامر (CMD) داخل مجلّد `bridge`:
```bash
pip install -r requirements.txt
```

### 2) عرّف المفتاح السرّي (اختر مفتاحاً طويلاً عشوائياً)
في **نفس نافذة CMD**:
```bash
set BRIDGE_SECRET=ضع_هنا_مفتاحا_طويلا_وعشوائيا
```
> احتفظ بهذا المفتاح — ستضعه في موقعك لاحقاً (في نافذة الربط).

### 3) شغّل الجسر
```bash
python bridge.py
```
سيعمل على: `http://localhost:8799` (لا تغلقه أثناء التداول).

### 4) ارفع الجسر للإنترنت برابط ثابت (Cloudflare Tunnel)
افتح **نافذة CMD ثانية**:
```bash
cloudflared tunnel --url http://localhost:8799
```
سيظهر رابط مثل:
```
https://abc-def-123.trycloudflare.com
```
> هذا هو **"رابط الجسر"** الذي تضعه في موقعك. (رابط TryCloudflare يتغيّر عند
> إعادة التشغيل؛ لرابط ثابت تماماً أنشئ "Named Tunnel" مجاني من Cloudflare.)

## 🖥️ أين تُدخل بياناتك؟ (خلاصة سريعة)

| البيان | أين يُدخل |
|--------|-----------|
| **رابط الجسر** (من cloudflared) | في **موقعك** → نافذة "ربط MT5" |
| **المفتاح السرّي** (`BRIDGE_SECRET`) | في **موقعك** → نافذة "ربط MT5" |
| **Login / Password / Server** لحسابك | في **موقعك** → نافذة "ربط MT5" |
| `BRIDGE_SECRET` (تعريف متغيّر البيئة) | على **جهازك** في CMD قبل تشغيل الجسر |

> 🔒 كلمة مرور الوسيط لا تُخزَّن في موقعك — تُرسل مشفّرة (HTTPS) للجسر على جهازك
> وتُستخدم للجلسة فقط.

## 🧪 اختبر الجسر قبل ربط الموقع

بعد تشغيل `python bridge.py`، افتح المتصفح على:
```

```

## ⚠️ تنبيهات أمان

1. **لا تشارك `BRIDGE_SECRET`** مع أحد.
2. **ابدأ بحساب ديمو** — الحساب الحقيقي = مخاطرة حقيقية.
3. إن أُغلق جهازك أو انقطع الإنترنت ⇒ الجسر يتوقّف ⇒ لا تنفيذ حتى يعود.
4. لتفعيل **24/7 حقيقي** بلا جهازك ⇒ انقل نفس `bridge.py` إلى VPS ويندوز رخيص (~$5/شهر).
